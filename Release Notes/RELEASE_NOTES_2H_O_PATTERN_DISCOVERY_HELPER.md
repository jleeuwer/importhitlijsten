# Release Notes — Sprint 2H-O Pattern discovery helper

## Nieuw

- Pattern discovery helper voor String Patterns.
- Importsamenvatting toont kandidaatpattern-aantallen.
- Edit-scherm krijgt knop **Pattern suggesties**.
- Suggesties sluiten aan op de bestaande tabel `public.string_del_patterns`.
- Remaster/remastered met jaartal wordt slim gegroepeerd.
- Bestaande patterns worden case-insensitive herkend.

## Veiligheidsregels

- Geen automatische titelwijzigingen.
- Geen automatische stagingmutaties.
- Geen nieuwe database-tabel.
- Geen wildcard/regexopslag in deze sprint.
